# CAD Source Reference

The mechanical/CAD design used for this project was taken from the Dorian Borian Sesame Robot project.

Official source repository:
https://github.com/dorianborian/sesame-robot

CAD directory:
https://github.com/dorianborian/sesame-robot/tree/main/hardware/cad

The source CAD directory contains:
- Sesame-ESP32-v122.f3z
- Sesame-ESP32-v122.step

This project uses the Sesame mechanical/CAD design while implementing the robot with the project's own ESP32-based electronics and firmware.

The actual CAD binaries are not duplicated in this archive because the connected GitHub file interface available here cannot download binary CAD blobs into the ZIP. The official source links above point directly to the original CAD files.
